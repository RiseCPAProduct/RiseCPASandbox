# Competitive Matrix

Source: FigJam board "Competitors" (Direct Competitor, Indirect Competitor,
Substitution, and Feature List and Analysis sections), combined into one
matrix.

Competitors covered:

- Direct: Google Drive, MEGA
- Indirect: Slack, Asana
- Substitution: USB drives

## How to read the scores

- 1 = weak or lacking, 3 = functional or average, 5 = best in class.
- Criteria and weights come from the board's Feature List and Analysis.
- Scores marked `*` were set on the board. Unmarked scores are new, filled in
  from the board's feature checklists, comparison tables and competitor notes
  so that every competitor is scored on every criterion.
- Weighted Score = sum of (score x weight). It is also on a 1–5 scale.

## 2. Strengths and Weaknesses

| Competitor | Type | Score | Strong at | Weak at |
|---|---|:---:|---|---|
| Asana | Indirect | 3.80 | Task management (best in class); clear roles, owners and deadlines; multiple views of the same work (list, board, calendar, timeline, Gantt) | Not built for document storage; no department/topic spaces; no visual resource landing page; no messaging |
| Slack | Indirect | 3.40 | Department/topic spaces (channels); 2,600+ app integrations; generous free plan; enterprise and AI-assisted search; workflow automation | Conversation-based, not a document home; no task management; no visual landing page; files get buried in messages |
| Google Drive | Direct | 3.15 | Real-time collaboration; viewer/commenter/editor permissions; AI search including scanned text; version history; 15GB free; Google Workspace integration | Folder-based only, with no department/topic spaces; generic landing page; task management limited to @-mention assignments |
| MEGA | Direct | 2.50 | Security and encryption (MEGA can't read user data); data redundancy across countries; version history and automatic backups; usage dashboard for businesses | Folder-based only; few integrations; no task management or messaging; storage-first rather than an internal information hub |
| USB Drives | Substitution | 1.55 | Offline and portable; one-time cost with no subscription; works on any OS | No central storage, search, permissions or sharing beyond handing over the drive; data is lost if the drive is lost |

## 4. How Each One Works (from the board)

| Criteria | Google Drive | MEGA | Slack | Asana | USB Drives |
|---|---|---|---|---|---|
| Primary Purpose | Centralized storage for multiple users | Centralized storage focused on user security | Team communication | Project & task management | Portable storage, backups and transfers |
| Information Organization | Folder-based | Folder-based | Channels | Projects & tasks | Folders (only when plugged in) |
| Navigation Structure | Folder-based | Folder-based | Workspace -> Channel | Workspace -> Project -> Task | Folder-based |
| Finding Information | Search + folders + AI | Search + folders + AI | Search across messages & files | Search across projects & tasks | Folder navigation |
| Collaboration Style | Document sharing and access | Document sharing and access | Conversation-based | Task-based | Share the physical drive |
| Main Content | Files, documents, photos, videos | Files, documents, photos, videos | Messages, files & conversations | Tasks, projects & work resources | Files, documents, photos, videos |
| Best Use | Company and personal use | Company and personal use | Team communication | Managing work & responsibilities | Company and personal use |
